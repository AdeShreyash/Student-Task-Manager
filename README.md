
# Student Task Manager

A beginner-friendly command-line task management application developed using Python. It helps students organize academic tasks, manage deadlines, set priorities, and track completed work.

## Features

- Add new tasks
- View all tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Set task due dates
- Assign priorities: High, Medium, Low
- Save tasks permanently using JSON file storage

## Technologies Used

- Python 3
- JSON
- Python File Handling

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

   ```bash
   python task_manager.py
   ```

6. Follow the instructions displayed in the terminal.
